= Preconfigura il firmware di sistema prima di un aggiornamento del software ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partire da ONTAP 9.17.1, se un firmware BIOS o LOADER più recente è già presente sul dispositivo di avvio di un nodo prima di eseguire un aggiornamento automatico non interruttivo (ANDU), il processo di aggiornamento mantiene il firmware più recente invece di sovrascriverlo con la versione inclusa nell'immagine ONTAP. Questo permette sia l'aggiornamento del software ONTAP che l'aggiornamento del firmware di completarsi in un unico ciclo di riavvio.

In ONTAP 9.16.1 e versioni precedenti, un ANDU installa sempre il firmware BIOS e LOADER incluso nell'immagine di ONTAP di destinazione, indipendentemente dalla versione del firmware già presente sul dispositivo di avvio. Se è stata scaricata separatamente un'immagine di servizio BIOS o LOADER più recente, dopo l'aggiornamento di ONTAP è necessario eseguire un ciclo di takeover e giveback separato per attivare il firmware più recente.

A partire da ONTAP 9.17.1, ONTAP confronta le versioni del firmware BIOS e LOADER presenti sul dispositivo di avvio di ciascun nodo con le versioni incluse nell'immagine di destinazione di ONTAP. Se il dispositivo di avvio contiene già una versione più recente di quella inclusa, il firmware incluso non viene installato. Il firmware più recente già presente viene mantenuto. Se la versione inclusa è uguale o più recente di quella presente sul dispositivo di avvio, il firmware incluso viene installato.

Dopo il riavvio del nodo come parte del normale flusso di lavoro ANDU, il firmware sul dispositivo di avvio viene attivato così che sia l'aggiornamento ONTAP sia l'aggiornamento del firmware vengano completati con un unico riavvio.

.Prima di iniziare
* Tutti i nodi del cluster devono eseguire ONTAP 9.17.1 o versioni successive.
* Devi aver scaricato l'immagine del servizio BIOS o LOADER più recente da link:https://mysupport.netapp.com/site/downloads/firmware/system-firmware-diagnostics["Sito di supporto NetApp"^].
+
Devi avere il livello di privilegi avanzati per scaricare il firmware sul dispositivo di avvio di un nodo.



.Fasi
. Impostare il livello di privilegio su Advanced (avanzato):
+
[source, cli]
----
set -privilege advanced
----
. Scarica l'immagine di servizio più recente sul dispositivo di avvio di ciascun nodo:
+
[source, cli]
----
system node firmware download -node <node_name> -package
----
+
Ripeti questo passaggio per ogni nodo del cluster che deve ricevere il firmware più recente.

. Torna ai privilegi di amministratore:
+
[source, cli]
----
set -privilege admin
----
. Verifica la versione del firmware attualmente presente sul dispositivo di avvio di ciascun nodo:
+
[source, cli]
----
system node firmware bootmedia show
----
+
La versione del firmware preinstallato deve essere superiore alla versione inclusa nell'immagine ONTAP di destinazione.



.Quali sono le prossime novità?
* Dopo aver preconfigurato il firmware, sei pronto per link:../upgrade/automated-upgrade-task.html["esegui un aggiornamento ONTAP automatizzato"].
+
Durante l'aggiornamento, ONTAP rileva che il dispositivo di avvio contiene già una versione più recente del firmware BIOS e LOADER e la conserva. Il firmware incluso non viene installato sui nodi che dispongono già di una versione più recente.
