= Modificare la password di un amministratore ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dovresti modificare la password iniziale dell'amministratore ONTAP subito dopo il primo accesso e periodicamente in seguito, per contribuire a mantenere sicuro il cluster.

A partire da ONTAP 9.20.1, se il tuo account utente è configurato per gli avvisi di scadenza della password, System Manager visualizza un banner di avviso a partire da 14 giorni prima della scadenza della password. L'avviso si aggiorna a ogni accesso per mostrare il numero di giorni rimanenti.

.A proposito di questa attività
La nuova password deve rispettare le seguenti regole:

* Non può contenere il nome utente
* La lunghezza deve essere di almeno otto caratteri
* Deve contenere almeno una lettera e un numero
* Non può essere uguale alle ultime sei password



NOTE: È possibile utilizzare il `security login role config modify` comando per modificare le regole delle password per gli account associati a un determinato ruolo.

.Prima di iniziare
* Per modificare la password, è necessario essere un amministratore del cluster o di SVM.
* Per modificare la password di un altro amministratore, è necessario essere un amministratore del cluster.


.Fasi
Utilizza System Manager o l'interfaccia a riga di comando (CLI) di ONTAP per modificare la tua password.

[role="tabbed-block"]
====
.System Manager
--
. In System Manager, selezionare *Cluster > Settings*.
. In *Utenti e ruoli*, seleziona *Utenti*.
. Seleziona image:icon_kabob.gif["Menu"] accanto all'account utente per cui devi modificare la password, quindi seleziona *Cambia password*.
. Inserisci la nuova password.
. Reinserisci la nuova password per confermarla, quindi seleziona *Salva*.


--
.CLI
--
Se sei un amministratore SVM, puoi usare il `security login password` comando per cambiare la tua password. Se sei un amministratore del cluster, puoi usare il `security login password` comando per cambiare la password di qualsiasi amministratore.

. Modifica della password di amministratore: `security login password -vserver _svm_name_ -username _user_name_`
+
Il seguente comando modifica la password dell'amministratore `admin1` per l'SVM `vs1.example.com`. Ti viene chiesto di inserire la password corrente, quindi di inserire e reinserire la nuova password.

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----
