= Scopri il supporto di ONTAP per la sicurezza FC-SP-3
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
A partire da ONTAP 9.20.1, ONTAP supporta l'autenticazione e la crittografia Fibre Channel Security Protocol 3 (FC-SP-3) per gli adattatori host bus (HBA) sicuri di Broadcom su alcuni sistemi ONTAP. FC-SP-3 fornisce crittografia a livello hardware e autenticazione del dispositivo per contribuire a proteggere i dati in transito tra gli host FC e NVMe/FC e i sistemi storage ONTAP da intercettazioni, manomissioni e accessi non autorizzati, mantenendo al contempo le prestazioni e l'allineamento agli standard di sicurezza FC T11.

I seguenti HBA sicuri Broadcom supportano FC-SP-3:

* Schede target: LPe38104
* Schede initiator: LPe38102 (64G), LPe37102 (32G)


Usa lo link:https://hwu.netapp.com/["NetApp Hardware Universe"^] per verificare se il tuo sistema ONTAP specifico supporta gli HBA richiesti.

Puoi anche usare il `fcp adapter show -fields transport-security-supported` comando per verificare se il tuo HBA supporta FC-SP-3. Il campo *transport-security-supported* è *true* quando FC-SP-3 è supportato.



[[enable-fc-sp-3-support]]
== Abilita il supporto FC-SP-3

Se la configurazione supporta FC-SP-3, puoi abilitarlo quando link:../networking/create_a_lif.html["creare"] o link:../networking/modify_a_lif.html["modifica"] un'interfaccia di rete (LIF) impostando l' `-fc-transport-security option` su *mandatory* o *preferred*. Imposta l'opzione su *mandatory* per impedire agli host che non supportano FC-SP-3 di accedere al sistema storage. Imposta l'opzione su *preferred* per fare in modo che ONTAP tenti una connessione FC-SP-3, consentendo comunque l'accesso all'host se non è possibile stabilire FC-SP-3.
