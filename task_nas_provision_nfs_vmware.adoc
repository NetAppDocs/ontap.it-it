= Fornire storage NFS per datastore VMware con ONTAP System Manager
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Prima di usare ONTAP tools for VMware vSphere per effettuare il provisioning di volumi NFS su un sistema storage basato su ONTAP per host ESXi, abilita NFS tramite System Manager per ONTAP 9.7 o versioni successive.

Dopo aver creato un link:task_nas_enable_linux_nfs.html["Storage VM abilitato per NFS"] in System Manager, puoi poi eseguire il provisioning dei volumi NFS e gestire i datastore usando ONTAP tools for VMware vSphere.

Assicurati di controllare la  https://imt.netapp.com/matrix/["Matrice di interoperabilità NetApp"^] per confermare la compatibilità tra la tua versione attuale di ONTAP e le release di ONTAP tools for VMware vSphere.

Per configurare l'accesso NFS per gli host ESXi ai datastore utilizzando System Manager Classic (per ONTAP 9.7 e versioni precedenti), vedi https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["Panoramica sulla configurazione di NFS per ESXi"^]

Per ulteriori informazioni, vedi https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["TR-4597: VMware vSphere per ONTAP"^] e il https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["Tool ONTAP per la documentazione di VMware vSphere"^].
