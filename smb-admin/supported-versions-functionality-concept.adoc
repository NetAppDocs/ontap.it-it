= Versioni e funzionalità di ONTAP SMB supportate
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Server Message Block (SMB) è un protocollo di condivisione file remota utilizzato da client e server Microsoft Windows. ONTAP supporta tutte le versioni di SMB. Devi verificare che il server SMB di ONTAP supporti i client e le funzionalità richieste nel tuo ambiente.

Le informazioni più recenti sui client SMB e sui controller di dominio supportati da ONTAP sono disponibili nello strumento _matrice di interoperabilità_.

SMB 2.0 e le versioni successive sono abilitate per impostazione predefinita per i server SMB di ONTAP e possono essere attivate o disattivate secondo necessità. Analogamente, SMB 1.0 può essere attivato o disattivato secondo necessità.

A partire da ONTAP 9.20.1, ONTAP supporta le query SMB con nome normalizzato per file e directory aperti. I client Windows possono recuperare i nomi canonici di file e directory con una singola richiesta.

[NOTE]
====
Le impostazioni predefinite per le connessioni SMB 1.0 e 2.0 ai controller di dominio dipendono anche dalla versione di ONTAP. Scopri di più sul comando  `vserver cifs security modify` nella link:https://docs.netapp.com/us-en/ontap-cli/vserver-cifs-security-modify.html["Riferimento al comando ONTAP"^]. Per gli ambienti con server CIFS esistenti che eseguono SMB 1.0, NetApp consiglia di eseguire la migrazione a una versione successiva di SMB il prima possibile per prepararti ai miglioramenti della sicurezza e della conformità. Contatta il tuo rappresentante NetApp per ulteriori dettagli.
