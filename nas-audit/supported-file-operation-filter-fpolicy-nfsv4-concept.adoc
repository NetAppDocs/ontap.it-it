= Operazioni e filtri file FPolicy supportati per NFSv4 in ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Quando si configura l'evento FPolicy, è necessario tenere presente che solo alcune combinazioni di operazioni e filtri dei file sono supportate per il monitoraggio delle operazioni di accesso ai file NFSv4.

A partire da ONTAP 9.15.1, FPolicy supporta il protocollo NFSv4,1.

A partire da ONTAP 9.19.1, gli amministratori possono controllare la disponibilità di NFSv4.2 a livello di SVM, abilitando o disabilitando il protocollo per le singole storage VM tramite System Manager, la CLI o la REST API.

A partire da ONTAP 9.20.1, FPolicy supporta il monitoraggio degli eventi di accesso ai file NFSv4.2, incluse le nuove operazioni sui file per le scritture di attributi estesi (xattr) e i filtri delle etichette di sicurezza per l'attività di Labeled NFS. Scopri di più su link:../nfs-admin/enable-disable-nfs-task.html["Abilitare o disabilitare NFS per le SVM di ONTAP"].


NOTE: I filtri delle etichette di sicurezza (`setattr_with_security_label_change` e `getattr_with_security_label_read`) richiedono che le etichette di sicurezza NFSv4.2 (Labeled NFS) siano abilitate sulla SVM. Scopri di più su link:../nfs-admin/enable-nfsv42-security-labels-task.html["abilitare le etichette di sicurezza NFSv4.2"]. `getxattr` e `listxattrs` sono operazioni di sola lettura e FPolicy non le monitora.
