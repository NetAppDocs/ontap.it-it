= Installazione e configurazione del server ONTAP Vscan
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Impostare uno o più server Vscan per verificare che i file sul sistema vengano sottoposti a scansione antivirus. Seguire le istruzioni fornite dal fornitore per installare e configurare il software antivirus sul server.

Segui le istruzioni contenute nel file README fornito da NetApp per installare e configurare ONTAP Antivirus Connector. In alternativa, segui le link:install-ontap-antivirus-connector-task.html["Pagina installare il connettore antivirus ONTAP"] istruzioni.

[NOTE]
====
Per le configurazioni di disaster recovery e MetroCluster, è necessario configurare server Vscan separati per i cluster ONTAP primario/locale e secondario/partner.

====


[[antivirus-software-requirements]]
== Requisiti del software antivirus

* Per informazioni sui requisiti del software antivirus, consultare la documentazione del vendor.
* Per informazioni sui fornitori, i software e le versioni supportati da Vscan, consulta link:../antivirus/vscan-partner-solutions.html["Soluzioni partner di Vscan"].




[[ontap-antivirus-connector-requirements]]
== Requisiti del connettore antivirus ONTAP

Ogni SVM utilizza ICAP o Antivirus Connector, non entrambi.

* Puoi scaricare ONTAP Antivirus Connector dalla link:http://mysupport.netapp.com/NOW/cgi-bin/software["Download del software"^] pagina sul NetApp Support Site.
* Per informazioni sulle versioni di Windows supportate dal connettore antivirus ONTAP e sui requisiti di interoperabilità, vedere link:../antivirus/vscan-partner-solutions.html["Soluzioni partner di Vscan"].
+
[NOTE]
====
È possibile installare diverse versioni dei server Windows per diversi server Vscan in un cluster.

====
* Sul server Windows deve essere installato .NET 3.0 o versione successiva.
* SMB 2.0 deve essere attivato sul server Windows.




[[icap-capable-scan-engine-requirements]]
== Requisiti del motore di scansione compatibile con ICAP

Ogni SVM utilizza ICAP o Antivirus Connector, non entrambi.

* A partire dalla versione ONTAP 9.20.1, ONTAP supporta un percorso di scansione basato su ICAP che elimina la necessità di Antivirus Connector.
* ICAP supporta motori di scansione basati su Linux e non richiede Windows, .NET o SMB 2.0.



NOTE: Se esegui il downgrade da ONTAP 9.20.1 a una versione precedente, devi prima rimuovere tutte le configurazioni ICAP.

Scopri di più su link:icap-vscan.html["Configurazioni Vscan basate su ICAP"].
