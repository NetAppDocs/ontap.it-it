= Flusso di lavoro per le verifiche post-aggiornamento di ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Dopo l'aggiornamento di ONTAP, è necessario eseguire diverse attività per verificare la disponibilità del cluster.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Uno"]Verifica il tuo cluster.
[role="quick-margin-para"]
Dopo l'aggiornamento di ONTAP, dovresti link:task_verify_cluster_after_upgrade.html["verifica la versione del cluster, lo stato di salute del cluster e lo stato di salute dello storage"]. Se stai usando una configurazione FC MetroCluster, devi anche verificare che il cluster sia abilitato per il passaggio automatico non pianificato.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Due"]Verifica che tutti i LIF siano sulle porte home.
[role="quick-margin-para"]
Durante un riavvio, alcuni LIF potrebbero essere stati migrati alle porte di failover assegnate. Dopo aver aggiornato un cluster, devi link:task_enabling_and_reverting_lifs_to_home_ports_post_upgrade.html["abilita e ripristina tutti i LIF che non si trovano sulle loro porte home"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Tre"]Verifica le considerazioni speciali specifiche per il tuo cluster.
[role="quick-margin-para"]
Se alcune configurazioni esistono sul tuo cluster, potresti dover link:concept_special_configurations_post_checks.html["Esegui ulteriori passaggi dopo l'aggiornamento"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quattro"]Aggiorna il Disk Qualification Package (DQP).
[role="quick-margin-para"]
Il DQP non viene aggiornato come parte di un aggiornamento ONTAP. Devi link:concept_when_you_need_to_update_the_disk_qualification_package.html["aggiorna il DQP"] dopo l'aggiornamento.
